Function: xmlfragment()

Call Signature

xmlfragment(vId, vFragment, oController?): any

Loads and instantiates an XML-based fragment.

To instantiate a fragment that is already defined separately, call:


sap.ui.xmlfragment(sId?, sFragmentName, oController?);

Advanced usage:


sap.ui.xmlfragment(oFragmentConfig, oController?);

In addition to an id, the oFragmentConfig object can have either a fragmentName or a fragmentContent property, but not both.

Parameters

vId

string | { fragmentContent?: string; fragmentName?: string; id?: string; }

ID of the created fragment which will be used as prefix to all contained control IDs. If the first argument is not an ID, it must be either the fragment name (sFragmentName) or a configuration object (oFragmentConfig) as specified below

string

Type Literal

{ fragmentContent?: string; fragmentName?: string; id?: string; }

ID of the created fragment which will be used as prefix to all contained control IDs. If the first argument is not an ID, it must be either the fragment name (sFragmentName) or a configuration object (oFragmentConfig) as specified below

fragmentContent?

string

definition of the fragment content as an XML string that will be used instead of loading the content from a separate .fragment.xml file. When this property is given, any given fragment name is ignored

fragmentName?

string

resource name of the fragment module in dot notation without the .fragment.xml suffix from the file name

id?

string

ID of the created fragment which will be used as prefix to all contained control IDs

vFragment

any

resource name of the fragment module as specified by vId.fragmentName or, in the advanced usage case, an optional oController

oController?

any

controller object to be used for methods or event handlers. Can be either the controller of an enclosing view, a new controller instance, or a simple object with the necessary methods attached. Note that a fragment has no runtime representation besides its contained controls. Therefore, there is no API to retrieve the controller from the return value. Note also that fragments may require a controller to be given and certain methods to be available

Returns

any

the instantiated root control(s) from the fragment content

Deprecated

As of version 1.58. Refer to topic:04129b2798c447368f4c8922c3c33cd7 Instantiation of Fragments.
